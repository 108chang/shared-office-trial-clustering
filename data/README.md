# 데이터 안내

코드잇 스프린트 DA16 PART3 중급2 팀 프로젝트에 사용된 공유오피스 무료체험 고객 데이터입니다. 최종 보고서·발표 PDF, 통합 Colab 노트북, 원본 CSV 5개와 데이터 명세서가 제공됐습니다. 공개 다운로드 링크와 재배포 허용 범위는 확인되지 않았습니다.

## 전체 실행에 필요한 파일

| 파일 | 필수 열(노트북에서 사용) | 의미 |
|---|---|---|
| `trial_register.csv` | `user_uuid`, `trial_date` | 고객별 체험 신청일 |
| `trial_visit_info.csv` | `user_uuid`, `site_id`, `date`, `stay_time_second`, `first_enter_time`, `last_leave_time` | 날짜·지점별 재실초, 첫 입실·마지막 퇴실 시각 |
| `trial_access_log.csv` | `user_uuid`, `checkin`, `cdate`, `site_id` | 출입 사건, UTC 기록 시각 |
| `trial_payment.csv` | `user_uuid`, `is_payment` | 고객별 결제 여부(0/1) |

필수 열은 실제 CSV와 코드에서 확인했습니다. 방문 테이블에는 `stay_time`, 출입 테이블에는 `id`도 포함됩니다. 결제 여부는 고객별로 일관되어야 하며 시각 열에는 소수 초 등 혼합 형식이 포함됩니다.

| 실제 원본 파일 | 행 수 | 고유 고객 수 |
|---|---:|---:|
| trial_register | 9,659 | 9,624 |
| trial_visit_info | 11,477 | 6,534 |
| trial_access_log | 63,708 | 6,026 |
| trial_payment | 9,659 | 9,624 |
| site_area | 9 | 해당 없음 |

[원본 데이터 명세서](../docs/data_dictionary.xlsx)는 구조 참고 자료로 제공합니다. 명세서의 `user_id`는 실제 CSV의 `user_uuid`, 신청 테이블의 `timestamp`는 `trial_date`, 출입 테이블의 `timestamp`는 `cdate`에 대응합니다. 지점 면적도 명세서의 `area`와 실제 CSV의 `area_pyeong`이 다릅니다. 실행에는 실제 CSV 열 이름을 사용하세요.

저장소 루트의 `data/private/`에 네 파일을 두세요. `site_area.csv`는 노트북에서 읽지 않으므로 이 분석의 필수 입력이 아닙니다. 별도 전처리 CSV나 저장된 학습 모델 없이 네 원본에서 변수를 만들고 군집을 다시 학습하는 구조입니다.

## 공개 범위

사용자 식별자, 지점별 출입 시각과 결제 기록을 포함하는 개별 데이터는 공개 저장소에서 제외합니다. 제공된 원본 CSV는 로컬 검증에 사용하고 공개 업로드하지 않습니다. `data/private/`와 데이터 형식 파일은 `.gitignore`로 제외했습니다. 실제 행 데이터가 없는 명세서만 `docs/`에 보존했습니다.

## 기간과 분모

- 신청 기록: 2021-05-01 ~ 2023-12-31. 방문 기록은 2024-01-02까지 이어집니다.
- 신청 고객 9,624명 → 방문 고객 6,534명 → EDA 대상 6,207명 → 모든 이용일 시각이 관측된 모델링 대상 6,202명.
- 방문 고객의 관측 결제율 39.2%와 모델링 대상의 38.6%는 분모가 다릅니다.
- 결제 시점·금액·상품은 제공된 분석에서 확인할 수 없습니다. 관측 결제 여부는 행동보다 먼저 발생했을 가능성을 배제하지 못합니다.

분석 결과와 실행 검증 범위는 [노트북 안내](../notebooks/README.md)를 참고하세요.
